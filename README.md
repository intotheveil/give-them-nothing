# Give Them Nothing — play in your browser

**Play:** https://intotheveil.github.io/give-them-nothing/

A dark, cold visual novel adapted from the novel *Give Them Nothing* by A. Damon.
This repository holds only the compiled web build (Ren'Py 8.4.1). Source is private.

Content warning: suicide, self-harm, the deaths of children, mob violence.
